# Toyes Tech

Premium eCommerce platform for Phones, Laptops, and high-performance Accessories.

## Features
- Variant-aware shopping experience (Storage/RAM/Color selection)
- Hybrid mobile navigation with sticky action bars
- Functional Wishlist with localStorage persistence
- Secure mock Paystack payment integration
- Dynamic inventory-aware cart management

## Development
```bash
npm install
npm run dev
```
